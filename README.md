# Mission: Save the Monsoon Village

Interactive Disaster Management Simulator for a Grade 8 Science & Creativity Expo.

## How to Run

Open `index.html` in any modern browser. No installation, server, account, API, or build step is required.

## Project Files

- `index.html` - simulator screens and interface structure
- `style.css` - responsive layout, illustrated village map, animation, polish
- `script.js` - missions, scoring, dashboard updates, final report, optional sound
- `assets/` - prepared folders for images, sounds, and icons if future expo materials are added

## Features

- Animated monsoon title screen
- Interactive village map with eight missions
- Live dashboard for safety, homes, water, animals, power, environment, happiness, and score
- Scientific reasoning after every decision
- Custom modals, no browser popups
- Optional generated sound effects and rain ambience
- Final rescue report with achievements and rating
- Responsive layout for laptop, tablet, and mobile screens
